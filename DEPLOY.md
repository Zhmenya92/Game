**Для чого:** гейт 4 (`plan.md`, розділ 11) вимагає **мінімум двох тижнів** збору даних — інакше D7 не порахувати. Отже, потрібен бекенд, який стоїть безперервно і **не втрачає дані при перезапуску**.

Цей файл — послідовність кроків, а не огляд варіантів. Рішення 3 плану (хостинг) досі відкрите; нижче те, що я б обрав, і чому.

## 0. Що потрібно від вас

| Що | Де взяти | Без цього |
|---|---|---|

## 1. Куди це ставити

Бекенд — один процес на `node:http`, **без залежностей і без бази**. Стан відновлюється програванням журналу з диска. Це задає єдину справжню вимогу до хостингу: **постійний диск**.

| Варіант | Придатність | Чому |
|---|---|---|
| **Fly.io / Railway / Render** — звичайна VM або контейнер із томом | ✅ **рекомендую** | Постійний диск є, процес живе довго, SIGTERM обробляється. Нічого переписувати не треба |
| VPS (Hetzner, DigitalOcean) + `systemd` + Caddy для HTTPS | ✅ підходить | Найдешевше й найпередбачуваніше, але HTTPS і перезапуск на вас |
| **Cloudflare Workers** | ⚠️ не як є | Рекомендація плану, але Workers не мають ні постійного диска, ні довгого процесу. Треба переписати `Journal` на KV або D1 — робота на день, і краще її робити **після** гейта 4, а не замість нього |
| Vercel / будь-який serverless | ❌ | Ефемерна файлова система: журнал зникне разом з інстансом |

**Статику гри** (`game/dist`) можна віддавати звідки завгодно — це кілька файлів без стану. Можна тим самим процесом, можна Cloudflare Pages.

## 2. Оточення сервера

```
BOT_TOKEN=123456:AA...            # від BotFather
BOT_NAME=pavutyna_bot             # без @
APP_NAME=play                     # коротке ім'я Mini App
TELEGRAM_WEBHOOK_SECRET=<≥16 випадкових символів>
ADMIN_SECRET=<≥8 символів>        # ⚠️ ОБОВʼЯЗКОВО: без нього /dashboard,
                                  # /api/metrics і /api/stats відкриті всім,
                                  # хто знає адресу — разом із доходом і
                                  # текстами клієнтських помилок
ADSGRAM_SECRET=<випадкове>        # якщо є Adsgram
DATA_DIR=/data                    # ⚠️ ПОСТІЙНИЙ том, не /tmp
PORT=8790
```

**`DEV_ALLOW_UNSIGNED` не ставити.** Він дозволяє будь-кому вигадати собі `initData` і був потрібен лише для розробки без бота. З живим токеном він перетворює всю валідацію на декорацію.

**`DATA_DIR` має вказувати на постійний том.** Якщо його не задати, журнал вимикається і сервер працює як раніше — у пам'яті. Це зручно для розробки й катастрофічно для софтлончу: перший перезапуск зітре два тижні.

Клієнту при збірці:

```
VITE_API=https://ваш-домен       # інакше клієнт шукає API на сусідньому порту
VITE_ADSGRAM_BLOCK=<block id>    # якщо є Adsgram
```

## 3. Кроки

```bash
# 1. Зібрати гру
cd game
npm ci
VITE_API=https://ваш-домен npm run build     # dist/ — це вся статика

# 2. Перевірити, що все зелене ПЕРЕД викладкою
npm test

# 3. Викласти сервер (приклад для VPS)
#    Процес: node server/index.ts, робоча тека — game/
#    Перед стартом переконатись, що DATA_DIR існує й переживає перезапуск

# 4. Налаштувати бота — одна команда
BOT_TOKEN=... PUBLIC_URL=https://ваш-домен \
  TELEGRAM_WEBHOOK_SECRET=... GAME_URL=https://ваш-домен \
  node tools/setupBot.ts

# 5. Перевірити
curl https://ваш-домен/health
BOT_TOKEN=... node tools/setupBot.ts --check
```

`setupBot.ts` ставить команди (`/start`, `/paysupport` — обов'язковий за правилами Telegram для Stars), кнопку меню з входом у гру й вебхук із секретом.

⚠️ Скрипт **жодного разу не запускався проти живого Telegram** — токена немає. Форми запитів узяті з Bot API, і кожен крок друкує, що саме зробив, тож розбіжність буде видно з першого прогону.

## 5. Що дивитися під час двох тижнів

`https://ваш-домен/dashboard` — гейт 3, гейт 4, когорти, воронка, гроші.

| Коли | На що дивитись |
|---|---|
| Перший день | **Воронка.** Якщо люди не доходять до першого рану — проблема не в грі, а у вході |
| День 2 | **D1.** Перша цифра, яка щось означає. Поріг 27 % |
| Дні 2–7 | **Ghost-hook rate** (поріг 30 %) і **share rate** (2 %). Це перевірка диференціації, а не утримання |
| День 8+ | **D7** (10 %) і **K-фактор** (0.25) |

**Не робіть висновків раніше**, ніж когорта дозріє. Дашборд навмисно пише «ще рано» замість числа: людина, яка прийшла вчора, не може мати D7, і рахувати її як «не повернулася» означає занижувати ретеншен тим сильніше, чим швидше росте аудиторія.

## 7. Що ламається найчастіше

| Симптом | Причина | Що робити |
|---|---|---|
| Гра відкривається, але «офлайн» | `VITE_API` не заданий при збірці | пересобрати з правильним `VITE_API` |
| Оплати не нараховуються | вебхук не встановлений або секрет не збігається | `node tools/setupBot.ts --check` |
| Дані зникли після деплою | `DATA_DIR` не на постійному томі | перевірити монтування; журнал має лежати поза контейнером |
| `initData` не валідується | токен у сервера не той, що в бота | звірити `BOT_TOKEN` |
| Виклик відкривається, але траса інша | `APP_NAME` чи `BOT_NAME` не збігаються з BotFather | звірити |
| Дашборд показує «немає даних» на всьому | події не доходять: клієнт шле на інший домен | подивитись мережу в DevTools |
